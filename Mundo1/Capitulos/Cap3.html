HTML e CSS não são linguagens de programação, mas sim linguagens de marcação e estilo, respectivamente. HTML - HyperText Markup Language. CSS - Cascading Style Sheets. HTML é focada em estruturar o conteúdo, utilizando elementos como títulos, parágrafos, listas, links e imagens. Cada elemento HTML é representado por uma tag, que indica o tipo de conteúdo e sua função na página. CSS é responsável pelo designe do conteúdo estruturado pelo HTML. Com o CSS, é possível controlar cores, fontes, espaçamento, layout e outros aspectos visuais de uma página web. JAVA SCRIPT é uma linguagem de programação que permite adicionar interatividade e dinamismo às páginas web. Com o JavaScript, é possível criar efeitos visuais, validar formulários, manipular elementos da página e muito mais. Conteúdo em HTML:

Ele envolve o uso de HTML, CSS e JavaScript para criar páginas web interativas e responsivas. O front-end é responsável por tudo o que o usuário vê e interage diretamente no navegador. - Back-end é a parte do desenvolvimento web que lida com o servidor, banco de dados e lógica de aplicação. Ele envolve a criação de APIs, gerenciamento de dados e processamento de solicitações do usuário. O back-end é responsável por garantir que os dados sejam armazenados, processados e enviados corretamente para o front-end. - Full Stack é um termo que se refere a desenvolvedores que possuem habilidades tanto em front-end quanto em back-end. Um desenvolvedor Full Stack é capaz de trabalhar em todas as camadas de uma aplicação web, desde a interface do usuário até o servidor e banco de dados. PHP, JavaScript, Python, Ruby, C# e Java são algumas das linguagens de programação mais utilizadas no back-end
